# 门店短视频（本地配镜）

一家实体眼镜店的同城抖音内容仓库。目标不是涨粉，是**把附近 3 公里要配镜的人带到店里**。

## 目标

- 3 个月：账号发出 24 条成片，跑通"选题 → 拍摄 → 发布 → 看数据 → 改下一条"的循环
- 6 个月：把账号做成案例，接 3–5 家本地商家的代运营（300–1200 元/月/家）

## 目录

| 目录 | 放什么 |
|---|---|
| `01-选题库/` | 顾客最常问的问题、同行评论区的质疑，一条一个选题 |
| `02-脚本/` | 每个已拍或待拍的脚本：钩子、分镜、口播稿 |
| `03-拍摄清单/` | 器材、机位、封面、发布设置，固定下来不用每次想 |
| `04-数据记录/` | 每条视频的数据，以及从数据里得到的结论 |

## 每周节奏

- 周一：从选题库挑 2 条，写成脚本
- 周二、周四：各拍 1 条（店内空档 30 分钟就够）
- 周三、周五：22:00 前发布，当天把数据填进 `04-数据记录/`
- 周日：看这周哪条完播高、评论问了什么，写进"结论"

## 合规红线（写死，不要碰）

- 不说"治疗 / 矫正 / 治愈近视"，不承诺降度数
- 不用"全市最低 / 史上最便宜 / 第一"这类极限词
- 不点名贬低同行，只讲"怎么判断"，不讲"谁家坑"
- 价格只说真实在售的套餐，边界（含什么、什么情况加钱）必须讲清
